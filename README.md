# 🍫 Chocolate Sales Analysis using Machine Learning

## 📌 Project Overview
This project analyzes chocolate sales data to uncover sales trends, product performance, and customer behavior using **machine learning techniques**.

## 🎯 Objectives
- Analyze historical chocolate sales data
- Identify key factors influencing sales
- Build predictive models for sales forecasting

## 🧹 Data Preprocessing
- Cleaned and prepared sales data
- Handled missing values
- Performed feature engineering

## 📈 Exploratory Data Analysis (EDA)
- Analyzed sales trends over time
- Studied product-wise and region-wise performance
- Identified seasonal demand patterns

## 🤖 Machine Learning Models
- Built regression-based machine learning models
- Compared model performance
- Evaluated using:
  - RMSE
  - MAE
  - R² Score

## 📊 Results & Insights
- Identified high-performing products
- Discovered seasonal sales trends
- Generated insights for inventory and sales planning

## 🛠️ Tech Stack
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Scikit-learn
